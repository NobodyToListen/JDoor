# Code of conduct

We are committed to a respectful, harassment-free project for everyone.

Be constructive, assume good intent, respect privacy, and critique code rather than people.
Harassment, discrimination, doxxing, threats, and sharing another person’s private screen or
session data are not acceptable.

Report conduct concerns privately to the repository maintainers. Maintainers may edit or remove
content and restrict participation when necessary to protect the community.
